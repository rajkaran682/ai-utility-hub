# AI Utility Hub v1

Mobile-first starter for an all-in-one utility website.

Included working browser tools: Word Counter, Case Converter, Extra Space Cleaner, Percentage Calculator, Age Calculator, BMI Calculator, Password Generator, JSON Formatter, Base64 Encoder/Decoder, Text-to-Slug, Image Compressor and Image Resizer.

## Render
Create a new GitHub repo, upload all files, then create a Render Web Service using Docker. No API key is needed for v1.

Next phases: AI integration, PDF/video/audio workers, login/history, subscriptions, ads, SEO landing pages and usage limits.
